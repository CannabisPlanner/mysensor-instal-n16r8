MySensor Hub

ESP32-S3 N16R8 (16 MB flash, 8 MB PSRAM)

Connect your ESP32-S3 to the computer via USB cable, then click the button below.

This browser does not support Web Serial. Use Chrome or Edge on a computer. Web Serial requires HTTPS.

Only works in Chrome or Edge on desktop (Windows/Mac/Linux/ChromeOS). Does not work on mobile or in Firefox/Safari.
This build is for the 16 MB / 8 MB PSRAM board only. For the 4 MB version, go back to the main page.
